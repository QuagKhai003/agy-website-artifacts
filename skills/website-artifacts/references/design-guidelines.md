# Apple HIG Minimalist Monochromatic Glassmorphism & Anti-AI-Slop Design Guidelines

Every interface generated by `agy-website-artifacts` (Portal, Lock Screen, Task Layouts, and custom `publish_html_artifact` UIs) MUST follow this design system unless the user explicitly specifies another brand theme.

---

## 1. Strict Anti-AI-Slop Rules (Hard Bans)

Avoid every visual cliché associated with generic AI-generated web UIs:

1. **No Eyebrow / Kicker Micro-Labels:**
   - **Never** place uppercase tracked micro-labels (`11px`, `letter-spacing: 0.08em`, `text-transform: uppercase`) or pill badges (`"LIVE SYNC"`, `"v2.0"`, `"AI POWERED"`) directly above headings.
   - Start cleanly with the page/view title itself.
2. **No Card-Inside-Card Nesting (Max 1 Surface Layer):**
   - **Never** nest bordered boxes or sub-cards inside glass cards (e.g., no bordered `.item` cards inside a `.glass` card, no bordered `.counter` box inside a `.panel` card).
   - Use **Apple Inset Grouped Surfaces**: one single translucent surface container whose internal rows or sections are separated solely by crisp `1px` hairline dividers (`var(--hairline)`).
3. **No "VibeCode Purple" / Neon Glow Gradients:**
   - **Never** use generic purple-indigo radial spotlight glows (`rgba(129,140,248,0.22)`), cyan-to-violet gradients, or decorative glowing orbs behind content.
   - Keep the canvas calm, quiet, and genuinely **monochromatic** (neutral obsidian / graphite / silver-ink shades with subtle ambient depth).
4. **No Emojis as UI Icons:**
   - **Never** prefix headings, buttons, or alerts with emojis (`🗂️`, `🎬`, `📝`, `✅`, `❌`, `⚡`, `🔍`, `📊`, `⌘`).
   - Use pure typography or crisp `16px` monochrome SVG line icons (`stroke="currentColor"`, `stroke-width="1.5"`, `fill="none"`).
5. **No Redundant Subtitle Fluff or Decorative Chrome:**
   - **Never** add generic explanatory filler sentences under every heading (e.g., *"Real-time PC <-> Mobile sync that persists on reload"*). Let clean controls and structure speak for themselves.
   - **Never** wrap views in fake device frames, debug toolbars, or excessive pill badges.
6. **No Heavy Drop Shadows or Unsolicited Bounce Animations:**
   - Rely on crisp `1px` borders, subtle translucent luminance contrast, and quiet `150ms ease` opacity/background transitions—never `box-shadow: 0 24px 60px` glow halos or bouncy hover scaling.

## 2. Monochromatic Design Tokens (Apple Dark Graphite + Frosted Material)

Use a single cohesive neutral-graphite monochromatic scale (`0` chroma distraction, pure luminance hierarchy):

```css
:root {
  /* Canvas & Material Surfaces */
  --canvas: #0b0b0d;                 /* Deep calm obsidian canvas */
  --surface: rgba(255, 255, 255, 0.045);       /* Primary frosted surface */
  --surface-hover: rgba(255, 255, 255, 0.075); /* Row / control hover */
  --surface-press: rgba(255, 255, 255, 0.105); /* Active / pressed */
  --surface-well: rgba(0, 0, 0, 0.28);         /* Recessed input / media well */
  --nav-glass: rgba(11, 11, 13, 0.72);         /* Sticky navigation bar material */

  /* Hairlines & Borders */
  --border: rgba(255, 255, 255, 0.095);        /* Outer material edge */
  --hairline: rgba(255, 255, 255, 0.075);      /* Internal 1px list divider */
  --highlight: rgba(255, 255, 255, 0.06);      /* Subtle top edge specular */

  /* Ink Hierarchy (WCAG AA compliant) */
  --ink-1: #f5f5f7;                  /* Primary text (Apple Off-White) */
  --ink-2: #a1a1a6;                  /* Secondary labels & metadata */
  --ink-3: #6e6e73;                  /* Tertiary hints & placeholders */

  /* Interactive Primary (High-Contrast Monochrome) */
  --action-bg: #f5f5f7;
  --action-ink: #0b0b0d;

  /* Semantic Indicators (Restrained, Desaturated — used only for explicit status/triage) */
  --state-ok: #d4d4d8;               /* Monochrome active / selected */
  --state-warn: #a1a1a6;
  --state-danger: #f87171;           /* Reserved strictly for destructive/error feedback */

  /* Geometry & Spacing (Apple 4pt / 8pt Grid) */
  --radius-lg: 14px;                 /* Grouped containers & modals */
  --radius-md: 10px;                 /* Inputs & primary controls */
  --radius-sm: 8px;                  /* Compact segmented controls */
  --space-1: 4px;
  --space-2: 8px;
  --space-3: 12px;
  --space-4: 16px;
  --space-5: 20px;
  --space-6: 24px;
}
```

### Glassmorphism Usage Rule
Apply `backdrop-filter: blur(24px) saturate(140%)` **sparingly and purposefully**:
- Sticky top navigation bars (`--nav-glass`) that scroll over content.
- Centered focal surfaces (Lock Screen sheet, single-card canvas, modals).
- Grouped inset containers (`--surface` + `1px solid var(--border)` + subtle top specular `inset 0 1px 0 var(--highlight)`).
- **Never** stack a blurred glass element inside another blurred glass element.

## 3. Typography & Optical Hierarchy (Apple HIG)

- **Font Stack:** `-apple-system, BlinkMacSystemFont, "SF Pro Display", "SF Pro Text", "Segoe UI", system-ui, sans-serif`
- **Antialiasing:** `-webkit-font-smoothing: antialiased; -moz-osx-font-smoothing: grayscale;`
- **Type Scale:**
  - Navigation / View Title (`h1`): `17px`–`20px`, `font-weight: 600`, `letter-spacing: -0.02em`, `color: var(--ink-1)`
  - Section Label (sits *outside* above an inset grouped list): `13px`, `font-weight: 500`, sentence case (NOT uppercase), `color: var(--ink-2)`, `margin: 0 0 8px 4px`
  - Body / Row Label: `14px`–`15px`, `font-weight: 400` or `500`, `line-height: 1.45`
  - Metadata / Captions: `12px`–`13px`, `color: var(--ink-2)`
  - Numeric Readouts (counters, KPIs, timestamps, file sizes, PINs): always apply `font-variant-numeric: tabular-nums;`

---

## 4. Layout & Structural Patterns (Zero Nesting)

1. **Navigation Header (Not a Floating Card):**
   - Full-width sticky bar at `top: 0` with `background: var(--nav-glass)`, `backdrop-filter: blur(20px) saturate(140%)`, and `border-bottom: 1px solid var(--hairline)`.
   - Never float the top bar as a detached rounded box with drop shadow.
2. **Inset Grouped Lists (macOS / iOS Settings Pattern):**
   - Wrap related rows in one `.group` container (`border-radius: var(--radius-lg)`, `background: var(--surface)`, `border: 1px solid var(--border)`).
   - Separate rows with `border-top: 1px solid var(--hairline)` on `.row + .row`—zero gaps, zero nested borders, zero inner rounded cards.
3. **Segmented Controls (Instead of Pill Spam):**
   - Group related filter/mode switches inside a compact segmented track (`background: var(--surface-well)`, `padding: 3px`, `border-radius: 10px`, `border: 1px solid var(--hairline)`), with the active segment elevated via `background: rgba(255,255,255,0.12)` and `color: var(--ink-1)`.
4. **Input, Placeholder & Control Alignment (Zero Optical Drift):**
   - Always give single-line `<input>` elements an explicit height (`height: 42px` on desktop, `44px` on mobile), symmetrical horizontal padding (`padding: 0 14px`), `-webkit-appearance: none`, and **identical `font-family`, `font-size`, and `line-height` on both `input` and `input::placeholder`** (`opacity: 1`) so placeholder text never drifts up/down across Chrome/Safari/iOS.
   - For centered tracked inputs (e.g., PIN inputs with `letter-spacing: 0.22em`), balance the trailing kerning with `text-indent: 0.22em` and reset both via `input:placeholder-shown { letter-spacing: normal; text-indent: 0; }` so the placeholder is dead-center.
   - Match heights of adjacent inputs and buttons (`42px` / `44px`), and align section labels (`padding: 0 16px`) directly with the inner text rail (`16px`) of inset grouped lists.
5. **Responsive Ergonomics:**
   - Mobile (`<640px`): single-column flow, minimum `44px` touch target height on interactive rows/buttons, `env(safe-area-inset-*)` respected.
   - Tablet (`640–1024px`) & Desktop (`>1024px`): centered max-width reading measure (`520px` for focused tools/portals, `1080px` for split review workspaces), generous breathing room (`20px`–`32px`).
